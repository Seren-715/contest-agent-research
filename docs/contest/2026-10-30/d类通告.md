D类变更新闻内容：
**关于更新 D 类离线实验材料与运行指南的通知**

平台已更新《D 类离线实验材料与运行指南（改版）》，最新版文件名为 `research-experiments-20261020-source-v1.zip`。相比此前版本，本版重点说明平台现行的源码来源核验要求，以及选手 Agent 需要调整的操作流程，具体如下。

**一、源码由“自行完成后提交”改为“本轮本题模型生成后提交”**

旧版指南要求将 `implementation.py` 复制到本队可写工作区，完成其中的 `run_experiment(request)`，再提交平台执行。当前要求 Agent 读取题目材料后，必须通过赛事 Gateway，在本轮本题会话中请求大模型生成完整实现，再将模型返回的源码原样保存为 `implementation.py`。

本队可写工作区仍可用于保存源码、公开自测和日志。变化在于源码的产生方式：不得直接提交由 Agent 自行编写、修改或镜像预置的完整实现。仅调用一次模型，再执行与该次回复无关的代码，也不能满足要求。

**二、正式实验增加源码来源核验，平台执行存档源码**

提交后，平台会核验源码是否与本轮本题的真实模型回复一致；通过后生成绑定当前队伍、评测和题目的源码凭证。正式执行器直接读取凭证对应的平台存档源码运行，不接受 Agent 替换为其他代码。其他题目、其他队伍或历史评测的凭证不能复用。

执行命令的参数形式保持，并不代表旧版 Agent 自动兼容。正式参赛须使用平台当前挂载的 `run_experiment.py` 客户端，不要使用镜像中缓存的旧版客户端或旧入口直接上传源码执行。

**三、修复源码也必须经过模型生成流程**

公开自测出现错误时，Agent 应将错误反馈给本轮本题会话中的模型，要求重新返回完整修复源码，再原样保存并提交。不得在模型返回后自行拼接代码、补充导入、替换语句或修改算法实现。

模型回复必须完整；若回复被截断，应重新请求完整版本，不能自行补齐。正式实验锁定源码后，不能再更换另一份源码重跑。

**四、离线自测通过不等于取得正式实验资格**

离线材料可用于检查源码语法、公开样例、输入输出和文件保存，但离线自测不会签发平台源码凭证，也不会产生正式成绩。正式来源核验必须在平台当前授权的题目会话中完成；来源核验通过也不代表算法正确，仍须按真实实验结果接受判定。

**五、补充超时、代码错误和结果返回的排查要求**

请为模型生成、公开自测、模型修复及正式执行合理预留时间。Gateway 最终返回 HTTP 200，并不代表 Agent 已在自身截止时间前收到响应；应同时检查模型请求超时和整题剩余时间。

正式实验完成后，应按客户端返回的真实答卷保存并返回结果，避免因解析异常或占位失败答卷导致返回内容与可信实验记录不一致。出现问题时，请保留本轮评测 ID、`events.jsonl`、客户端输出及错误日志，勿公开密钥。

页面上的“Agent 返回结果或保存文件不符合赛题一输出规范”是通用提示，可能涉及来源核验、生成超时、程序错误或最终答卷不一致，不能一律理解为 JSON 格式错误。D 类出现该提示时，页面现已附带最新版指南的下载入口。

本版新增《Agent适配与源码来源要求》《报错对照与测试清单》，并同步更新运行指南、文档导航、客户端副本及源码提取工具，供选手按上述流程检查适配。**D-01、D-02、D-05 的算法方法、实验参数、公开样例及评分公式保持不变，本次材料更新不重算历史成绩。**请使用旧版材料开发 Agent 的选手下载最新版，重点检查源码生成、修复、客户端调用及最终结果返回流程。
