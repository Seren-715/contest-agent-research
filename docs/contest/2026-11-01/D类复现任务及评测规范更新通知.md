关于赛题一 D 类复现任务及评测规范更新的通知



各参赛队伍：



为明确 D 类任务的执行要求、评分依据及材料提供方式，现就赛题一 D-01、D-02、D-05 的相关规范通知如下。



一、任务目标与材料提供方式



D 类任务考察 Agent 在评测过程中阅读任务材料、实现指定方法并完成实验的能力。



赛前已向参赛队公开通用运行接口、运行环境、资源限制、最终答卷规范及评分规则。



正式测评任务的具体方法、参数、输入约束、算法内部输出要求及配套材料，仅在评测运行期间向 Agent 提供，**不作为赛前公开附件发布**。



Agent 应依据当轮材料完成任务，不得假设正式任务与公开练习题采用相同的方法、参数或实验条件。



指定方法的验收以当轮材料为准，不要求源码写法与参考实现相同。使用其他方法取得更高指标，不能替代对指定方法的复现要求。



隐藏测试条件、参考实现及正确答案不向参赛队开放。评测中提供的正式任务材料不得通过返回内容、文件、日志或其他方式向参赛队导出。



二、通用接口与镜像兼容



本次保持既有任务入口、材料路径、算法函数签名、正式实验调用方式和最终答卷接口兼容。



本次更新不新增通用接口迁移要求，也不因镜像内调用脚本的版本较旧而要求参赛队更换脚本或重新打包镜像。符合既有通用协议的调用方式继续适用。



Agent 应在评测时读取并处理当轮任务材料。具体算法字段、参数及内部结果结构可能随任务变化，不能固定假设其与练习题一致。



上述兼容性不保证针对旧题编写的算法、固定字段假设或按题语义自检继续适用于正式任务。



三、输出与执行要求



内部算法入口仍为 `run\_experiment(request)`。内部算法结果与最终 Reproduction 答卷是不同的对象，不得混用。



\- 内部算法应按当轮材料返回规定的字段、类型及嵌套结构。

\- 最终答卷继续遵守既有 `case\_id`、`status`、`metrics`、`figures` 规范。

\- 当轮材料中的字段和类型模板仅用于说明格式，占位符不能直接作为实际实验结果。

\- 实验应遵守既有运行环境和资源约束，不得读取隐藏标签、参考实现或未授权材料。

\- 实验未完成、指标缺失或没有有效图表时，应按协议如实提交，不得伪造完成状态、指标或图片。



四、分值与评分依据



每题总分仍为40分，实验流水线20分、数据与图表20分，各项分值保持不变。



评分按以下原则执行：



1\. 复现结果10分按指定方法的复现达成度验收，不以自行替换算法后的指标改善代替。

2\. 按实验条件和方法步骤验收，正确且可核验的部分保留相应部分分。

3\. 对应条件的方法结果通过验收后，才能取得该条件的候选测量及图表分；仅生成图片不自动获得图表分。

4\. 失败、缺失或不合格条件不从相应计分分母中删除。

5\. 没有形成任何可验收正式条件成果时，可能整题计零分。

6\. “协议有效”表示返回格式等协议检查通过；“证据完整”表示运行证据满足核验要求。两者均不代表算法正确或内容满分。



五、预置内容的允许与禁止范围



禁止在镜像中**预置按具体题目定制**、可直接指导该题求解的算法提示、伪代码、完整解法及语义校验器。

允许保留通用能力，包括：

\- 材料读取、接口解析和通用格式检查；

\- 通用自测、多候选生成和自动修复；

\- 本轮模型依据当前任务材料生成的实现和测试；

\- 在既定反馈范围内依据得分进行优化。



不得通过无关模型调用，或让模型原样复述预置完整实现等方式，规避本轮生成要求。



六、源码来源与运行证据



沿用现有赛事 Gateway、源码来源和 AgentRuntime 运行追踪要求。



每题正式执行的算法源码应来自本轮本题模型返回的完整实现。



源码来源校验只证明执行源码与本轮模型回复一致，不单独证明算法正确或预置内容合规。



无法形成可信运行证据时，平台按既有异常流程核查，不直接据此认定算法不合格或违规。经核查属于平台、网关或证据采集故障的，不作为有效零分成绩。



七、重复评测与反馈范围



正式评测可按平台开放安排重复发起，允许在既定规则内依据得分优化 Agent。



选手可见反馈范围维持既定安排，不开放正式任务材料下载、隐藏测试条件、参考答案、详细判题日志或原始运行证据。



详细运行及判分证据由平台保存，供管理员核查。相关材料不得通过提交产物或其他渠道向参赛队导出。



八、生效与历史记录



本通知适用于生效后新启动的相关评测。



本次更新不涉及其他题目类别及其他赛题的规则调整。正式比赛的总分汇总与其他安排，仍以赛事已公布规则为准。



请各队阅读公开的通用接口及评分规范，检查 Agent 的动态材料读取、通用输出处理、源码来源和运行追踪能力。
