# 当前规则适配与验证（2026-10-26）

本分支基于上游 `46c6d43`，范围为当前规则上限、预算及超时结果一致性。上游 README 中的历史镜像、平台评测分和上传状态不能视为本分支验收。

## 规则与行为

依据本轮获取的官方公开 [输入输出规范](http://8.149.132.48/api/v1/challenges/challenge-tbd/materials/research-agent-spec) 和 [评分规则](http://8.149.132.48/api/v1/challenges/challenge-tbd/materials/research-scoring-rules)，采用 2026-10-24 更新及 `ce-quality-v3-20261024` 最终覆盖条款。

- C 正文 800～5000 字符，数字引用组最多 40 次；`[1,2]` 计一组。E 正文 800～4500 字符。标题行及参考文献节排除，正文空格、标点、换行保留计数。
- 提示、生成后审查、schema 与写文件前校验使用同一规则。超限让模型重新输出完整报告，不截断报告凑合提交。
- E 生成失败明确失败，不再使用程序拼接的通用方案或重复文字。Survey 只允许实际材料摘录兜底，摘录不足或超限也失败。
- A/B 外层上限 540 秒，C/D/E 为 900 秒；配置只能缩短，不能延长官方上限。默认内部预算预留 10 秒校验、落盘和返回。
- D 生成、修复及 Token 参数降级重试按剩余时间扣除正式实验预留。正式客户端等待上限为 `min(剩余预算, 880秒)`，不再固定 120 秒，也不在截止后强行启动。840 秒执行和 870 秒 RPC 由当前挂载的官方客户端与平台服务约束，不修改 vendor 客户端。
- 超时或取消时撤销后台写权限，并终止已注册的正式客户端进程，再处理失败返回。同步线程仍可能完成已开始的模型请求，但不能覆盖答卷或继续启动模型/正式实验请求。
- 文件采用 UTF-8 字节原子替换，Markdown 按字节回读。没有合法 C/E 结果时 HTTP 返回 503/504 错误，而不是以空字段或通用模板伪装成功。

## 本地验证

隔离环境运行，不使用真实网关、模型 Key 或正式题目。Python 包兼容范围更新为 3.9～3.11，以包含官方主容器 Python 3.11；D 源码仍要求 Python 3.9 标准库。

```text
.venv\Scripts\python.exe -m pytest -o addopts= -q -ra
Python 3.9.25: 83 passed, 1 skipped
.venv-py311\Scripts\python.exe -m pytest -o addopts= -q -ra
Python 3.11.15: 83 passed, 1 skipped
```

跳过项需要未纳入仓库的 `vendor/reference`，不能把它算作参考算法验收通过。真实 worker 子进程已跑公开测试中的模拟模型源码；正式客户端、模型及 SDK 路由的测试均使用替身。新 HTTP 测试覆盖原始八字段请求、直接返回五类答卷、失败 E 不留非法结果，以及超时后后台不能覆盖已返回文件。

Windows 自测使用父进程 timeout；支持 SIGALRM 的 Linux 保留内部 alarm。子进程通信显式使用 UTF-8，避免中文样例受宿主编码影响。
